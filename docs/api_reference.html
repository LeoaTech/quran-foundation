Authentication
JWT-based. All protected routes require Authorization: Bearer <token>
POST/auth/loginObtain access + refresh tokens
Public
Request body
{ "phone": "+923001234567", "password": "string", "center_id": "uuid" // optional — scopes the session }
Response 200
{ "access_token": "eyJ...", // expires 15 min "refresh_token": "eyJ...", // expires 30 days "user": { "id": "uuid", "full_name": "Ustad Tariq", "full_name_ur": "استاد طارق", "preferred_lang": "ur", "roles": ["teacher"], "center_id": "uuid" } }
POST/auth/refreshExchange refresh token for new access token
Public
Request body
{ "refresh_token": "eyJ..." }
Response 200
{ "access_token": "eyJ..." }
POST/auth/logoutRevoke refresh token
Any authenticated
Request body
{ "refresh_token": "eyJ..." }
POST/auth/signupSelf-register with a center approval code
Public
Request body
{ "full_name": "Hamza Rauf", "full_name_ur": "حمزہ رؤف", "phone": "+923001234567", "password": "string (min 8 chars)", "approval_code": "GUL-2026" // issued by center manager }
Response 201
{ "id": "uuid", "full_name": "Hamza Rauf", "status": "pending_approval" }
Notes
Account is created with status=pending_approval. Center manager must activate it before the user can sign in. Returns 400 INVALID_APPROVAL_CODE if the code is unknown or expired.

Notes
Called by the frontend immediately after a successful /auth/refresh to populate user state without requiring a full login. Returns 401 if the access token is missing or invalid.

Base URL & auth conventions
Global rules that apply to every endpoint.
Base URL
https://api.nurlms.org/v1
Authentication header
Authorization: Bearer <access_token>
Content type
Content-Type: application/json Accept-Language: ur // optional — returns bilingual fields in preferred order
Role hierarchy
super_admin > center_manager > teacher > student/guardian Higher roles inherit lower-role access within their scope. center_manager can only see data within their center(s). teacher can only see data within their assigned class(es).
Urdu/Arabic text handling
All *_ur and *_ar fields accept Unicode UTF-8. Max length: 500 chars for varchar, unlimited for text fields.
Errors & pagination
Standard error shape and cursor-based pagination.
Error envelope
{ "error": { "code": "ENROLLMENT_CONFLICT", "message": "Student is already enrolled in this class", "message_ur": "طالب علم پہلے سے اس کلاس میں داخل ہے", "field": "student_user_id", "status": 409 } }
HTTP status codes used
200 OK 201 Created 204 No content (DELETE) 400 Bad request / validation error 401 Unauthenticated 403 Forbidden (insufficient role) 404 Not found 409 Conflict 422 Unprocessable entity 429 Rate limited 500 Server error
Pagination
// Request GET /classes/:id/enrollments?page=2&per_page=20 // Response body { "data": [ ... ], "meta": { "page": 2, "per_page": 20, "total": 87, "total_pages": 5 }}
