Changed. SURAHS removed. Replaced by TOPICS, created by admin teachers per course — free-form, bilingual. TOPIC_SUBTOPICS lets teachers optionally break a topic into finer units.

Changed. PROGRESS_LOGS replaced by PROGRESS_SESSIONS (classwork) + HOMEWORK_ENTRIES (1-to-1). HOMEWORK_CRITERIA is the admin-defined template per class. HOMEWORK_SCORES records per-criterion marks per student.

Unchanged. Organizations, centers, and classrooms. name_ur / name_ar carry Urdu/Arabic text stored as UTF-8.

Unchanged. One USERS table for all roles. RBAC via USER_ROLES junction. preferred_lang drives RTL rendering per user.

Unchanged. Assessments and oral evaluations. Results now reference TOPICS via topic_tested_id instead of surahs.
